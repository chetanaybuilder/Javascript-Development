Day 4 — Roast Me App 🔥

A small API-powered application that fetches a random joke and displays it when the user clicks the Roast Me button.

Concepts Practiced

* addEventListener()
* Click events
* fetch()
* Promises
* .then()
* .json()
* .catch()
* DOM updates
* Working with API responses

API Flow

User clicks "Roast Me"
        ↓
Event listener detects the click
        ↓
fetch() requests data from the API
        ↓
Promise waits for the response
        ↓
.then() handles the response
        ↓
.json() converts the response into JavaScript data
        ↓
Joke is displayed in the DOM
        ↓
.catch() handles errors

⸻

Day 5 — Interactive Live Quiz 🧠

A live 10-question quiz application that fetches questions from the Open Trivia Database API and dynamically displays them using JavaScript.

Users answer each question, receive immediate feedback, track their score, and see their final result after completing the quiz.

Concepts Practiced

* fetch()
* APIs
* async / await
* JSON
* DOM manipulation
* Event listeners
* Arrays
* Objects
* Functions
* if / else
* Math.random()
* Dynamic element creation
* Score tracking

API Flow

User starts the quiz
        ↓
JavaScript calls the Quiz API
        ↓
API returns 10 questions
        ↓
JSON data is converted into JavaScript data
        ↓
Questions are rendered dynamically
        ↓
User selects an answer
        ↓
JavaScript checks the answer
        ↓
Score is updated
        ↓
Next question is displayed
        ↓
After 10 questions → Final Score
